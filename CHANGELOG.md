# Changelog

All notable changes to CommonFunLib are documented here.

## [1.0.4] - 2026-09-07

### Changed

- Redesigned every tool-category splash screen around its category icon.
- Added distinct visual treatments for Functions, Generators, Converters, and Hashing while preserving theme and font selection.
- Made category splash catalogs more expressive with oversized icon marks, stamps, animated treatments, and reduced-motion support.
- Bumped the npm package to `1.0.4` for the next release iteration.

## [1.0.3] - 2026-09-07

### Added

- Added `isValidEmail` and `truncate` common helpers with API routes and playground entries.
- Added readable `generateUsername` values from the bundled name banks.
- Added pressure conversion for Pa, kPa, bar, PSI, and atm.
- Added URL encode/decode helpers and API tools.
- Added QR code generation and 5 MB-limited SteganoPass file derivation.
- Added npm-package fallback execution to the web playground when the API is unavailable.
- Added live API status telemetry and a full catalog splash/overview experience.

### Changed

- Expanded CommonJS, ESM, and TypeScript package exports for every new helper.
- Marked the Java implementation deprecated and directed new work to the npm/API implementation.
- Improved upload errors with explicit browser and API messages for files over 5 MB.

## [1.0.1]

- Added the current converter, generator, hashing, and utility expansion before the 1.0.3 release bundle.
