# CommonFunLib 1.0.5

CommonFunLib 1.0.5 adds a compact batch of practical, dependency-free tools.

## Highlights

- `isValidUrl` for HTTP/HTTPS URL checks.
- `characterCount` for Unicode-aware text length checks.
- `generateBoolean` for cryptographically random true/false values.
- `convertAngle` for degrees, radians, and gradians.
- `hexEncode` and `hexDecode` for UTF-8 hexadecimal workflows.
- Every new tool is available through the package, API, web catalog, and npm fallback.

## Install

```sh
npm install commonfunlib@1.0.5
```
