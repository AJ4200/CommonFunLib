# CommonFunLib 1.0.4

CommonFunLib 1.0.4 is a focused presentation release for the web catalog.

## Highlights

- Functions, Generators, Converters, and Hashing each have a distinct splash treatment.
- Category icons are oversized and become the visual anchor of each workspace.
- Splash visuals inherit the active theme and font selection.
- Tool catalogs remain visible during each category intro.
- Reduced-motion preferences disable the decorative icon animation.

## Install

```sh
npm install commonfunlib@1.0.4
```
