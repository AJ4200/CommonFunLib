# CommonFunLib 1.0.6

CommonFunLib 1.0.6 adds four catalog tools across the npm package, Express API, web playground, offline fallback, and category navigation:

- `isLeapYear(year)` checks Gregorian leap years.
- `generateRandomDate(start, end)` returns a random ISO date in a bounded range.
- `convertVolume(value, fromUnit, toUnit)` converts liquid, cooking, imperial, and cubic-meter units.
- `sha3_384(input)` creates a SHA3-384 digest.

## Install

```sh
npm install commonfunlib@1.0.6
```
